¿Qué es una Máquina Universal de Ensayos?

Es el pilar de la ingeniería. Sometemos materiales a fuerzas controladas para descubrir sus secretos: su resistencia, rigidez y ductilidad. Estos datos son la base para construir todo lo que nos rodea de forma segura.

Explora los Ensayos Fundamentales

↔️ Ensayo de Tensión

Estiramos un material hasta que se rompe. Ideal para medir la ductilidad y resistencia de metales y polímeros.

  • Clave del Gráfico: Busca el Módulo de Young (rigidez) y el punto más alto (resistencia máxima).

↕️ Ensayo de Compresión

Comprimimos un material para ver cómo resiste el aplastamiento. Esencial para materiales frágiles como cerámicos.

  • Clave del Gráfico: Observa si el material falla de forma súbita (frágil) o si se deforma y ensancha.

🔄 Ensayo de Torsión

Retorcemos el material. Fundamental para entender el comportamiento de ejes y tornillos.

  • Clave del Gráfico: Permite obtener la resistencia del material a ser "cortado" o distorsionado.
